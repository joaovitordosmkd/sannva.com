Conecte o sistema ao Firebase da sua empresa

Cada empresa usa o próprio projeto Firebase. Assim os seus produtos, clientes e vendas ficam só com você e nunca se misturam com os de outra empresa.

Conferindo a configuração atual…

1Crie o projeto e o app Web

  1. Abra o console do Firebase com a conta Google da empresa e clique em Criar projeto (ex.: “DistribuiPro - Minha Empresa”). O Google Analytics pode ficar desligado.
  2. Dentro do projeto, clique no ícone Web </> (Adicionar app), dê um apelido como “DistribuiPro Web” e clique em Registrar app.
  3. Copie o bloco const firebaseConfig = { … } que aparece na tela. Se fechar, ele fica em Configurações do projeto › Geral › Seus apps.
